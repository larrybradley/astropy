Added an ``x0`` parameter to ``AsinhStretch`` that sets the zero point
of the asinh curve independently of the black point (``vmin``). This
allows an asinh stretch with its zero point at the sky level and the
black point set below the sky. The parameter is also available as
``asinh_x0`` in ``simple_norm`` and ``SimpleNorm``. ``SinhStretch`` has
a matching ``x0`` parameter, available as ``sinh_x0`` in
``simple_norm`` and ``SimpleNorm``, and the inverse of each stretch is
the other stretch for any ``x0``. Also added an ``AsinhNorm`` class
that creates an asinh normalization with the zero point at the
background level of the image. Its softening and lower cut level are
set in units of the background noise, and its upper cut level is set
by a percentile. The background and noise are estimated from each image
with sigma clipping unless they are input.
